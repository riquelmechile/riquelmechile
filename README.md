### MCP Doctor Chile · Investigación y colaboración

<p align="center">
  <a href="https://github.com/riquelmechile/riquelmechile/blob/main/RESEARCH_COLLABORATION.md"><img src="https://raw.githubusercontent.com/riquelmechile/riquelmechile/main/assets/projects/doctor-chile.svg" width="100%" alt="MCP Doctor Chile: buscamos colaboradores clínicos y técnicos para investigación con casos sintéticos"></a>
</p>

**MCP Doctor Chile** es el nombre de presentación de **Harness Médico Chile**, una investigación privada y experimental sobre evaluación de razonamiento clínico entre modelos de IA, evidencia y contexto sanitario chileno. Hoy es **solo investigación con casos sintéticos**, no un producto clínico, servicio diagnóstico ni sistema validado para pacientes.

**Buscamos colaboración:** médicos, investigadores clínicos, interoperabilidad FHIR/HL7, evaluación de IA, seguridad y privacidad. La hipótesis por estudiar es si la comparación independiente y la crítica cruzada entre modelos aportan valor frente a un modelo individual; **no se afirma una mejora médica demostrada**.

**[Cómo colaborar, límites de seguridad y contacto →](https://github.com/riquelmechile/riquelmechile/blob/main/RESEARCH_COLLABORATION.md)**

## La variedad no es dispersión. Es búsqueda de estructura.

Soy **neurodivergente**. Mi manera de trabajar conecta problemas de comercio, finanzas, infraestructura, regulación, contenido e investigación. El interés común es cómo hacer que una decisión sea **autorizada, trazable, verificable y económicamente razonable**.
