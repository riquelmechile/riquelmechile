# MCP Doctor Chile · Invitación a colaborar

**Nombre de presentación:** MCP Doctor Chile. **Proyecto de investigación:** Harness Médico Chile (repositorio privado).

**Estado: experimental, solo casos sintéticos.** No es un dispositivo médico, servicio de diagnóstico, sistema de triaje, aplicación para pacientes ni una plataforma clínicamente validada.

## Qué queremos investigar

¿Puede una evaluación de IA con **hipótesis independientes, crítica cruzada y verificación externa de evidencia** identificar errores de razonamiento que no aparecen cuando responde un solo modelo?

El proyecto compara diseños de paneles multiagente utilizando protocolos y casos sintéticos, y busca incluir contexto de Chile: terminologías sanitarias, referencias MINSAL, Fonasa, GES e interoperabilidad clínica. Es una **hipótesis evaluable**, no una mejora clínica ya demostrada.

## Colaboraciones que buscamos

| Área | Contribución potencial |
| --- | --- |
| Medicina y especialidades clínicas | Definir criterios de seguridad, revisar protocolos de casos sintéticos y adjudicar resultados de investigación |
| Investigación universitaria y bioestadística | Diseñar comparaciones reproducibles, muestras, métricas e intervalos de incertidumbre |
| Interoperabilidad e informática biomédica | Revisar FHIR R4, HL7 Chile, terminologías y fuentes oficiales |
| Seguridad, privacidad y derecho sanitario | Revisar límites regulatorios, anonimización, aislamiento, identidad y riesgos |
| Ingeniería de IA, MCP y evaluación | Proponer pruebas, observabilidad y verificación de evidencia sin tratar datos de pacientes |

## Qué existe y qué falta

**En desarrollo:** prototipos de casos sintéticos, hipótesis ciegas, evaluación comparativa, herramientas MCP de investigación y adaptadores para información sanitaria chilena.

**Pendiente de validación:** integración real completa de modelos, desidentificación auditada, estudios clínicamente adjudicados, seguridad externa y revisión regulatoria. Las pruebas de software no prueban eficacia clínica.
